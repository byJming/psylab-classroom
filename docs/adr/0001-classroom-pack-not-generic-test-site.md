# ADR 0001：产品核心是课堂实验包，不是泛心理测试站

## 状态

Accepted

## 背景

公众心理测试内容容易获得点击，但“有结果”不等于有科学解释。临床、人格、IQ 和能力标签会带来更高的伦理、版权和误导风险。通用浏览器实验构建器也已有成熟开源和商业替代品。

## 决策

PsyLab 的核心交付物是版本化的课堂实验包，并提供一个低风险公众体验入口。公众入口用于科学传播和试用，不能改变实验数据契约、风险边界和指标解释。

## 后果

- 实验包需要比普通 demo 多维护说明、许可、样例数据和测试。
- 不能用“测出你的某种能力”作为默认传播方式。
- 公众体验和高校教学可以共享 Definition、Runner 和 Metrics。
- 后续仍可增加开放量表，但必须逐项核验许可、中文版效度和结果边界。
