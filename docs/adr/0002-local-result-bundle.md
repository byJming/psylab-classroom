# ADR 0002：采用本地结果包与教师本地导入

## 状态

Accepted

## 背景

纯静态部署无法在没有后端的情况下自动接收学生结果。引入账号、数据库或云端收集会改变隐私、部署和维护边界，也不符合 Local-first 的初始目标。

## 决策

学生完成实验后导出 `Result Bundle`；教师使用本地导入页批量校验、去重和汇总。会话配置通过 URL fragment 或会话文件传递，不把结果发送到默认服务器。

## 后果

- 教师需要沿用学校已有 LMS、群组或文件提交方式传递结果包。
- 结果包 schema 必须稳定，错误导入必须可解释。
- 本地模式不能保证防作弊、身份认证或跨设备恢复。
- 后续可以增加自托管收集适配器，但不能让其成为运行实验的必要条件。
