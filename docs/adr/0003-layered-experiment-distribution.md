# ADR 0003：实验采用开放、引导、受控三级发布模型

## 状态

Accepted

## 背景

只保留低风险实验会压缩经典心理学范式的教学覆盖面；把所有范式公开为一键体验又会混淆科学传播、课堂教学和受控研究的伦理边界。技术实现优先级也不能替代分发规则：一个稳定的实验仍可能不适合公众运行。

## 决策

每个 Experiment Definition 必须声明 `runPolicy`：

- `open`：公众和课堂可运行。
- `guided`：仅从教师会话运行，要求教师确认和不可跳过的 debrief。
- `controlled`：源码可开源，但默认公共站点不展示或运行；部署者负责本地伦理、材料、参与者和设备条件。

`alpha/beta/stable` 继续表示实现稳定性，P0/P1/P2 继续表示实现优先级；两者不得替代 `runPolicy`。

## 后果

- 目录可以容纳错误记忆、注意盲视和部分社会范式，同时不把它们伪装成普通测试。
- 运行时、Result Bundle、导入器和文档必须保留并检查发布层级。
- 纯静态前端只能提供流程限制，不能证明伦理审批或阻止链接被公开转发。
- 受控层的存在不代表项目为其公开部署背书。
