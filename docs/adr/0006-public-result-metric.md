# ADR 0006：公众结果使用单一主指标，详细统计分层展示

## 状态

已接受

## 背景

公众体验者需要先理解“这次任务观察了什么”，而不是面对一组未经解释的研究统计量。与此同时，课堂和研究使用者需要保留完整的条件统计、清洗规则和版本信息。

## 决策

每个公开实验可以在 Definition 的 `metadata.publicMetric` 中声明一个面向大众的主指标。该指标必须：

- 对应一个已声明的 Metrics；
- 使用描述性语言，不输出人格、智力、临床或能力等级；
- 明确说明设备、浏览器和任务条件的限制；
- 不把公开用户结果自动转化为常模或跨设备排名；
- 允许 `invert100` 这类简单展示变换，但原始指标仍保留在 Result Bundle 中。

结果页先展示主指标，再展示条件表、详细指标、质量标记和方法版本。研究导出仍以原始 trial、清洗统计和代码本为准，主指标只影响公众阅读层，不改变数据契约。

## 影响

- 公众界面更容易理解，减少重复说明和研究术语。
- 研究员仍可以访问完整的 `raw`、`cleaned`、`byCondition` 和排除原因。
- 主指标必须随 Definition 版本一起审阅，不能在页面层随意添加。
- 任何“参考”都解释为本次任务内的描述性参考，不提供未经验证的群体常模。
