# 实验目录与筛选标准

## 1. 发布层级与风险边界

发布层级与 P0/P1/P2 技术优先级分离。P0/P1/P2 表示实现与验证顺序；`open`、`guided`、`controlled` 表示实验可以在哪里运行、需要什么告知与事后解释。

### 开放层（`open`）

开放层不是医学意义上的零风险，而是指在普通成人/高校教学与公众体验场景中：

- 不询问健康、创伤、性、身份、财务或违法经历。
- 不采集摄像头、麦克风、眼动、生理信号或定位。
- 不使用强闪烁、强噪声、惊吓或诱发性材料。
- 不需要欺骗、羞辱、公开排名或奖励惩罚。
- 结果只描述本次任务表现，不推断人格、智力或临床状态。
- 刺激可以程序化生成，或来源和许可清晰。

开放层实验仍需要说明、练习、退出按钮和完成后的简短解释。它们可以被公众体验馆和课堂模式直接列出。

### 引导层（`guided`）

引导层可包含轻度 surprise manipulation、欺骗或需要课堂讨论的范式。它们不出现在公众体验馆，只能从教师创建的会话启动，并要求教师确认、扩展说明和不可跳过的 debrief。

### 受控层（`controlled`）

受控层可涉及身份、负性情绪、社会互动、受控行为或高精度设备要求。Definition 和源码可以开源，但官方公共站点不提供运行入口。部署者必须自行完成材料、参与者资格、知情同意、伦理和设备验证。

### 官方不纳入

临床筛查、诊断、强应激、侵入性采集、明显伤害风险或许可不清的内容不进入官方实验包。开源代码不能替代审查，也不构成允许公开部署的许可。

## 2. 筛选维度

每个候选实验按五个维度评估：

1. **伦理风险**：是否涉及敏感内容、欺骗、压力或潜在负面反馈。
2. **版权风险**：刺激、量表、词表和图像是否可合法再分发。
3. **浏览器可行性**：是否依赖亚毫秒时序、音画同步、传感器或专用硬件。
4. **教学价值**：能否清楚讲解自变量、因变量和实验控制。
5. **结果可解释性**：能否提供描述性指标而不制造伪诊断。

## 3. 推荐实验池

以下 27 个实验均为 `open` 层候选，前提是使用原创/程序化刺激、无敏感材料和描述性结果。`P0` 是优先实现，`P1` 是完成核心运行时后扩展，`P2` 需要额外时序验证；P2 的技术验证不改变其开放层伦理边界。

| 优先级 | 实验 | 核心现象 | 主要指标 | 主要限制 |
|---|---|---|---|---|
| P0 | Simple RT | 反应速度与试次波动 | 中位数 RT、离散度 | 不做能力排名 |
| P0 | Choice RT | 选择数量对反应时的影响 | 条件 RT、正确率 | 按键映射需清楚 |
| P0 | Stroop | 刺激维度冲突 | 冲突效应、正确率 | 颜色词与字体需本地化 |
| P0 | Flanker | 周边干扰与选择反应 | 一致/不一致差值 | 使用箭头或原创符号 |
| P0 | Go/No-Go | 响应抑制 | 命中、漏答、虚报率 | 不解释为冲动性诊断 |
| P0 | Simon | 空间位置与反应规则冲突 | Simon effect | 使用抽象图形 |
| P0 | Visual Search | 特征与结合搜索 | 搜索 RT、正确率 | 试次数和显示布局固定 |
| P0 | Same-Different | 感知匹配与决策 | RT、正确率 | 刺激难度需平衡 |
| P0 | Mental Rotation | 空间旋转判断 | 角度斜率、正确率 | 图形全部原创生成 |
| P0 | Müller-Lyer / Ebbinghaus | 视觉错觉与知觉判断 | 估计偏差 | 不输出“空间能力”标签 |
| P1 | Posner Cueing | 注意线索与空间定向 | 线索效应 | 使用中性几何目标 |
| P1 | N-Back | 在线更新与记忆匹配 | 命中、虚报、条件差值 | 首版固定 1/2-back |
| P1 | Sternberg Memory Scanning | 记忆集合搜索 | 集合大小斜率 | 刺激只用数字/符号 |
| P1 | Digit Span（视觉正序） | 序列保持与回忆 | 最大长度、正确率 | 不称为 IQ 或记忆商 |
| P1 | Spatial Span / Corsi | 空间序列回忆 | 最大长度、正确率 | 使用固定网格 |
| P1 | Serial Position | 序列位置对回忆的影响 | 首因/近因比例 | 需要足够学习与回忆试次 |
| P1 | Recognition Memory | 再认与熟悉性 | 命中、虚报、敏感性 | 使用抽象图形，避免情绪材料 |
| P1 | Task Switching | 任务切换成本 | switch cost、错误率 | 规则说明不能过长 |
| P1 | Change Detection | 变化发现 | 命中、反应时 | 图形需原创、无惊吓元素 |
| P1 | Change Blindness | 视觉变化与注意 | 发现率、发现时间 | 需控制闪烁频率 |
| P1 | Serial Reaction Time | 序列学习 | 规则/随机差值 | 不推断运动学习能力 |
| P1 | Category Learning | 分类规则学习 | 学习曲线、正确率 | 规则和刺激公开 |
| P1 | Probability Learning | 反馈与概率选择 | 选择比例、学习曲线 | 不使用真实金钱或赌博反馈 |
| P2 | Attentional Blink | 快速序列注意 | T1/T2 命中率 | 对时序与刷新率敏感 |
| P2 | Stop-Signal | 停止信号与抑制 | SSRT、命中率 | 需专门时序验证，不做临床解释 |
| P2 | Temporal Order Judgment | 时间顺序判断 | 顺序正确率、阈值 | 需显示时序校准 |
| P2 | Speed-Accuracy Trade-off | 速度与准确率权衡 | RT-准确率曲线 | 结果解释需教学引导 |

## 4. 引导层与受控层候选

以下范式有明确教学或传播价值，但不应因“有趣”而降低发布边界。列入候选不代表已经通过实现、伦理或材料验收。

### 引导层候选

| 实验 | 核心现象 | 为什么不公开一键运行 | 最低要求 |
|---|---|---|---|
| Inattentional Blindness | 注意选择与意外刺激遗漏 | 依赖 surprise manipulation | 教师会话、完整 debrief、无羞辱性比较 |
| DRM False Memory | 关联词诱发的错误再认 | 涉及记忆错误和事后纠正 | 明确纠正误导、展示群体机制而非个人“记忆差” |
| Misinformation Effect | 事后信息改变记忆报告 | 需要受控误导与澄清 | 扩展说明、不可跳过 debrief、可退出 |
| Anchoring / Framing | 初始值或表述影响判断 | 结果易被误读为理性/能力标签 | 使用非敏感情境，只展示群体差异和方法解释 |
| Choice Blindness | 选择与理由的自我觉察 | 需要轻度欺骗 | 事后揭示操作、不得用于评价个体诚实或判断力 |
| Asch-like Conformity Simulation | 多数线索影响判断 | 包含模拟社会压力/欺骗 | 使用中性刺激、无同伴公开排名、及时解释 |

### 受控层候选

| 实验 | 核心现象 | 主要边界 | 官方实现要求 |
|---|---|---|---|
| Implicit Association Task | 联结强度与分类反应 | 身份、偏见和个人结果风险 | 不输出个人偏见标签；需本地材料与伦理审查 |
| Emotional Stroop / Dot-Probe | 情绪性线索与注意 | 负性或创伤性材料可能引发不适 | 材料分级、参与者支持与退出策略 |
| Cyberball | 社会排斥与归属感 | 可能诱发不适 | 不用于公众体验；需明确撤回与事后支持信息 |
| False Feedback / Learned Helplessness | 反馈影响行为与情绪 | 挫败、失败反馈和欺骗 | 不得使用羞辱性反馈；需单独伦理审查 |
| Iowa Gambling / Delay Discounting | 奖励、风险与时间偏好 | 容易被解释为财务/人格倾向 | 无真实金钱；结果不做现实行为推断 |
| High-precision Stop-Signal | 停止反应与抑制 | 对时序、设备和临床误读敏感 | 专门时序验证，不作为公开能力测试 |
| Audio-visual Temporal Tasks | 跨模态时序知觉 | 音画同步和设备差异 | 限定硬件/浏览器环境并记录校准 |

## 5. 首发建议

首个可用版本不必同时实现全部实验。建议先完成一个完整垂直切片，再按以下顺序扩展：

1. Simple RT：验证预检、键盘响应、存储和导出。
2. Stroop：验证条件设计、中文刺激和冲突指标。
3. Go/No-Go：验证正确/错误类型和质量标记。
4. Mental Rotation：验证程序化图形和不同难度条件。
5. Choice RT、Flanker、Simon、Visual Search：复用选择反应与均衡单元格组件（已实现，`definitionVersion 1.1.0`）。
6. N-Back、记忆扫描、Digit Span、Spatial Span：复用记忆序列组件；序列响应输入需先作为独立扩展设计。
7. 错觉、变化盲视、任务切换和序列学习：作为内容扩充。

## 6. 官方不纳入的类别

- 临床筛查、症状自评、心理健康风险评估。
- IQ、Raven、人格类型和付费版权测试的直接复制。
- 需要眼动、面部识别、摄像头、麦克风、触觉或生理传感器的任务。
- 强闪烁、强噪声、疼痛、睡眠剥夺、药物/酒精操作或其他明显安全风险的范式。
- 无法获得再分发许可的受保护题目、刺激、图像、音频、量表或数据集。
- 无法提供合格退出机制、事后说明或本地支持信息的高不适风险范式。

## 7. 试次生成与节奏规范（definitionVersion 1.1.0）

所有官方实验遵循同一套可复现的生成规则：给定 `experimentId + config + randomSeed`，试次序列完全确定（种子洗牌基于 `src/core/hash.ts` 的 `shuffle`）。每个试次编译为「注视期 → 响应窗 → 试次间隔」三段：

| 实验 | 注视期（含中央＋注视点） | 响应窗（可用 `config.responseWindowMs` 覆写） | 试次间隔 ITI | 提前反应处理 |
|---|---|---|---|---|
| Simple RT | 800–3000ms 随机 | 默认 2500ms | 300–700ms 随机 | 注视期按键立即结束试次，显示“按早了”反馈，记 `anticipation` |
| 颜色词 Stroop | 400–1000ms 随机 | 默认 2500ms | 300–700ms 随机 | 注视期按键被记录并记 `anticipation`，试次继续 |
| Go/No-Go | 400–1000ms 随机 | Go 默认 2500ms；No-Go 取响应窗与 1000ms 的较小值 | 300–700ms 随机 | 同 Simple RT |
| Mental Rotation | 400–1000ms 随机 | 默认 2500ms | 300–700ms 随机 | 同 Stroop |
| Choice RT | 400–1000ms 随机 | 默认 2500ms | 300–700ms 随机 | 同 Stroop |
| Flanker | 400–1000ms 随机 | 默认 2500ms | 300–700ms 随机 | 同 Stroop |
| Simon | 400–1000ms 随机 | 默认 2500ms | 300–700ms 随机 | 同 Stroop |
| Visual Search | 400–1000ms 随机 | 默认 2500ms | 300–700ms 随机 | 同 Stroop |

条件分配规则：

- **Stroop**：条件（一致/不一致）× 目标颜色（红/绿/蓝）共 6 个交叉单元格均衡，余数按固定轮转分配（各单元格计数差 ≤ 1）；不一致条件下的干扰词在另外两种颜色间交替，避免干扰词颜色与条件产生系统关联。整体序列由种子洗牌。
- **Mental Rotation**：同异（同形/镜像）× 角度（0/45/90/135°）共 8 个交叉单元格均衡后种子洗牌，不存在可预测的交替序列；两侧图形从竖直方向各旋转 ±angle/2，判断的相对角度差仍为 angle。
- **Go/No-Go**：按 `goRatio` 先生成 Go/No-Go 目标序列再整体种子洗牌；未加连续同类上限约束，宏观随机性由洗牌保证。
- **Simple RT**：单一目标条件，注视期随机时长即自变量。
- **Choice RT**：集合大小（2 选 1 / 4 选 1）× 该集合内颜色共 6 个交叉单元格均衡后种子洗牌；每种集合的颜色-按键映射固定（2 选 1：红 F/蓝 J；4 选 1：红 F、绿 G、蓝 J、紫 K），允许按键随试次导出。
- **Flanker**：条件（一致/不一致）× 中央目标方向（左/右）共 4 个交叉单元格均衡后种子洗牌；作答依据始终是中央箭头。
- **Simon**：条件（相容/不相容）× 位置（左/右）共 4 个交叉单元格均衡后种子洗牌；颜色由单元格唯一决定（相容：左红/右绿；不相容：左绿/右红），整体颜色平衡。
- **Visual Search**：搜索类型（特征/结合）× 陈列大小（4/8）× 目标出现（是/否）共 8 个交叉单元格均衡后种子洗牌；显示槽位固定，物品与槽位分配由 stimulusId 种子洗牌决定。

被试流程规范：练习阶段逐次显示对错/未响应/按早了反馈；练习结束出现过渡屏（含练习正确率，可“再练一次”或“开始正式测试”）；正式阶段不显示对错反馈。节奏字段（`fixationMs`/`itiMs`/`responseWindowMs`）随 trial 的 `data` 导出，见 `docs/data-contract.md`。

## 8. 每个实验的验收清单

- 有中文目的、背景、变量和适用课程说明。
- 有原创或许可清晰的刺激材料。
- 有练习阶段、退出路径和完成说明。
- 有固定随机种子样例和预期 trial 结构。
- 有至少一个指标单元测试和一个异常数据测试。
- 有明确的排除规则、质量标记和代码本。
- 结果页不出现诊断、人格、智力或医疗暗示。
- 可在支持的 Chrome/Edge Windows 环境完成并导出。
- 已声明 `runPolicy.tier`，并满足该层级的公开、告知、教师确认和 debrief 要求。
