# 隐私、合规与风险

## 1. 设计立场

PsyLab 默认处理的是浏览器中的实验行为数据，而不是个人档案。产品应遵循最小化、目的限定、透明告知、可删除和本地优先原则。本文件不是法律意见；学校部署前应由学校法务、伦理委员会或信息化部门复核。

## 2. 默认不采集

- 姓名、学号、手机号、邮箱和账号。
- IP、精确定位和联系人。
- 摄像头、麦克风、眼动、面部图像和生理信号。
- 完整 User-Agent、字体列表、精确屏幕尺寸和硬件指纹。
- 健康、诊断、治疗、创伤、性或身份信息。

匿名参与者代码由用户或教师在外部流程中管理。平台不应建立“代码—真实身份”映射。

## 3. 课堂告知文本基线

运行前应明确说明：

> 本实验用于心理学教学/科学体验，不是心理诊断或能力评估。结果默认保存在当前浏览器，清理浏览器数据可能导致未导出结果丢失。你可以随时退出，不需要填写姓名或学号。若教师要求提交结果，请使用课程指定的匿名代码。

教师若把结果与学生身份或成绩关联，相关责任不再由纯静态前端自动消除，应由学校确定处理目的、权限、保存期限和删除流程。

## 4. 实验发布层级与治理

| 层级 | 可使用内容 | 产品约束 |
|---|---|---|
| `open` | 无敏感材料、无欺骗、无个人标签的经典范式 | 可在公众页面运行；提供简短告知和退出路径 |
| `guided` | 含轻度 surprise manipulation、欺骗或需课堂讨论的范式 | 仅由教师会话启动；教师确认、扩展说明和不可跳过 debrief |
| `controlled` | 身份/情绪/社会排斥材料、受控行为任务或需时序/硬件验证的范式 | 不进入公共站点；部署者确认本地伦理、参与者资格、材料与退出支持 |

`guided` 和 `controlled` 的开源代码不等于公众适用。PsyLab 只提供流程提示和数据格式，无法替代学校伦理审查、知情同意或现场支持。

从 0.2 beta 起，产品不再把 `guided` 自动从公共目录隐藏。具体实验可以在目录中公开展示，并通过开始前的增强提示、参与者确认、退出路径和不可跳过的 debrief 限制运行流程。公共可见的意义是让用户能够审阅和选择，不是平台对所有场景作出适用性保证；教师、部署者和参与者仍可自行决定是否使用。

## 5. 威胁模型

| 风险 | 防护 |
|---|---|
| 浏览器清理导致数据丢失 | 完成后强制导出、IndexedDB 断点、导出校验 |
| 学生修改 URL 配置 | 显示配置哈希并在导入时校验；不把系统用于高风险考试 |
| 重复提交或多次尝试 | `attemptId`、导入去重和质量报告；不承诺防作弊 |
| 静态主机记录访问日志 | 无第三方资源，提供高校自托管/离线镜像，隐私说明列明日志边界 |
| 设备差异影响 RT | 记录粗粒度环境和质量标记，优先解释被试内差值 |
| 恶意结果文件 | JSON schema 校验、大小限制、未知字段警告、浏览器沙箱导入 |
| 第三方内容侵权 | 许可清单、来源记录、原创程序化刺激 |

## 6. 公共体验的结果边界

结果页面必须使用“本次任务表现”“条件差异”“有效 trial”等描述。禁止出现“正常/异常人格”“注意力缺陷”“智商等级”“适合/不适合某职业”等表达。

参考数据只能在任务版本、语言、样本和设备条件足够可比时展示。公开用户的自愿结果不能未经独立同意直接转化为常模数据集。

## 7. 伦理与退出

- 开始前提供简短说明和退出按钮。
- 不用失败反馈、排名或羞辱性文案提高完成率。
- 不以实验表现直接决定成绩。
- 对可能包含未成年人的公共页面使用更保守的内容和数据策略。
- `guided` 实验必须有不可跳过的事后解释；`controlled` 实验必须采用单独的材料审查和伦理流程，不得沿用开放层模板。

## 8. 内容许可

每个实验包必须包含 `LICENSES.md`，记录：刺激来源、词表来源、量表许可、字体许可、代码许可和修改说明。中文词表需要记录版本、来源和词频控制方法；不能因为“经典实验”而默认材料属于公共领域。
