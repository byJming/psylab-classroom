# 产品与范围

## 1. 定位

PsyLab 是一个开源的中文心理实验体验与教学平台。它把经典实验范式包装为可版本化的“实验包”，让用户在 Chrome/Edge 等现代浏览器中直接完成任务，并获得透明的行为指标、数据文件和方法说明。

核心承诺：

> 公众可以在几分钟内体验一个经典心理实验；教师可以在一节课内发起、收集并整理一个课堂实验；任何人都可以检查实验定义和指标代码。

## 2. 用户与场景

### 主要用户

| 用户 | 目标 | 主要痛点 |
|---|---|---|
| 心理学课程教师 | 快速组织课堂实验并拿到可用数据 | 软件安装、配置、数据合并、指标解释 |
| 助教 | 协助排查学生设备和整理结果 | 格式不统一、重复提交、异常记录难发现 |
| 心理学学生 | 完成实验并理解方法 | 不知道变量、指标和清洗规则 |
| 大众体验者 | 了解心理学现象 | 传统测试缺少解释，容易被贴标签 |
| 开源贡献者 | 添加实验或改进指标 | 缺少稳定数据契约和测试夹具 |

### 典型课堂任务

教师在课程开始前选择一个实验和 10/15/25 分钟预设，生成配置链接或会话文件；学生在桌面浏览器完成说明、练习和正式任务；学生下载单个结果 JSON 文件（文件名含实验、会话、匿名参与者代码和尝试号）并按学校已有渠道提交；教师在本地拖拽或整文件夹导入多个结果包，检查质量标记，导出 trial-level CSV、参与者摘要 CSV 和代码本。

### 典型公众任务

用户打开一个无账号体验页面，阅读简短说明，完成练习和正式任务；结果页面展示本次任务的中位数反应时、正确率、条件差异和质量提示，不输出诊断、人格标签、智力等级或医疗建议。

## 3. 产品模式

### 体验馆

- 仅展示 `open` 层实验：低风险、短时长、无敏感刺激。
- 默认本地保存，不上传实验结果。
- 结果以“本次任务表现”表述。
- 可下载 JSON/CSV 和方法说明。

### 课堂模式

- 由教师选择实验预设和受控参数。
- 可运行 `open` 层和 `guided` 层实验；`guided` 层必须显示扩展告知和事后解释。
- 配置通过 URL fragment 或 `.psylab-session.json` 传递。
- 学生使用匿名参与者代码，不要求姓名或学号。
- 结果包包含配置快照、实验版本、随机种子、原始 trial 和质量标记。
- 教师本地批量导入并生成汇总文件。

### 实验包仓库

每个实验包都包含：实验目的、理论背景、设计、变量、刺激生成规则、Definition、Runner、Metrics、参数 schema、排除规则、样例数据、代码本、许可信息和已知限制。

## 4. 实验发布层级

发布层级描述“如何分发和运行实验”，不是对实验理论价值的评价，也不等同于 `alpha/beta/stable` 实现稳定性。

| 层级 | 代码值 | 可见范围 | 最低运行要求 |
|---|---|---|---|
| 开放 | `open` | 公众体验馆和课堂模式 | 简短告知、退出路径、描述性结果 |
| 引导 | `guided` | 教师创建的课堂会话 | 教师确认、扩展说明、不可跳过的事后解释 |
| 受控 | `controlled` | 受控教学/研究部署 | 本地伦理和材料审查、参与者资格与部署责任确认；不进入公共站点 |
| 不纳入 | n/a | 不提供官方运行入口 | 临床、强应激、明显侵入性或许可不清的内容 |

浏览器静态页面无法替代伦理审查或防止链接转发。层级是产品发布和 UX 约束，不是访问控制或法律合规保证。

## 5. 明确不做

- ADHD、抑郁、焦虑、创伤等临床筛查或诊断。
- IQ、人格类型、能力排名和“脑龄”结论。
- 强制账号、课程管理、成绩系统和云端数据库。
- 摄像头、麦克风、眼动、面部表情或生理信号采集。
- 面向考试或高风险选拔的防作弊保证。
- 任意心理实验的可视化拖拽编辑器。
- 默认使用第三方分析脚本、广告、埋点或跨站追踪。

## 6. MVP 功能要求

### 必须有

1. 实验库与实验详情页。
2. 开放层实验的浏览器运行时，以及引导层所需的告知和事后解释框架。
3. 练习、预加载、桌面设备预检和失焦记录。
4. IndexedDB 本地断点状态。
5. JSON 完整结果包与 trial-level CSV 导出。
6. 教师本地批量导入、去重、配置一致性检查和摘要导出。
7. 指标定义、清洗规则和代码本可阅读、可下载。
8. 每个实验的样例数据、自动化指标测试和许可清单。

### 可以后置

- 自托管 JATOS 适配器。
- 实验包在线注册表和版本搜索。
- 自定义实验的代码扩展 API。
- 复杂的图形化作者工具。
- 公开的可选匿名参考数据收集。

## 7. 产品成功标准

- 教师在 5 分钟内完成预设选择并生成会话。
- 学生无需安装软件即可完成实验并下载结果包。
- 教师可以在本地 3 分钟内导入一个班级的结果并得到代码本。
- 结果包在不同浏览器和机器上能被识别为同一实验版本，异常记录有明确原因。
- 公众结果页不产生临床、人格或能力暗示。
