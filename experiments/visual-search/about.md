# Visual Search 视觉搜索

## 用途

用于比较简单特征搜索与困难结合搜索的效率差异。结果页以“聚焦搜索的效率”帮助公众理解本次任务，同时保留每个条件的试次数、正确率和反应时。

## 设计

- 被试内比较特征搜索与结合搜索、4 项与 8 项陈列。
- 目标始终是红色圆形；特征搜索的干扰物只有一种，结合搜索混有红方块与绿圆圈。
- 找到目标按 J，确定没有目标按 F；目标出现与不出现的试次平衡。
- 显示槽位固定，物品分配由随机种子决定；练习阶段不进入正式摘要。

## 主要指标

- 各搜索类型的陈列大小-反应时描述性斜率（ms/item）。
- 全部正式 trial 的总体正确率。
- 每个条件的正式 trial 数、正确率和清洗后中位数反应时。

## 分析边界

错误响应仍进入正确率分母，但不进入清洗后的反应时统计。失焦、无响应和提前反应必须保留原始记录与排除原因。斜率只描述本次任务的搜索过程，不是视觉能力或注意容量评分；色觉不可靠时不应解读结果。

## 当前状态

`open / beta`。升级为 `stable` 前还需要补齐陈列布局审阅、多刺激渲染的性能验证和真实课程试用记录。
